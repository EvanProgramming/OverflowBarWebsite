Quick answer. OverflowBar can move selected supported icons into a second row on macOS 15 and 26. It cannot manage every icon hidden by a MacBook notch, including protected controls and items without a safe, stable identity. See supported icon and troubleshooting details and compatibility notes.

Why are Mac menu bar icons hidden?

Sync tools, VPN clients, chat apps, and utilities often add status items to the right side of the Mac menu bar. The active app’s menus need space on the left. A MacBook camera notch further divides the available space.

When the bar gets crowded, icons can become difficult to reach or disappear from view. The exact behavior depends on your macOS version, screen layout, active application, and the status items involved.

Try these checks first

  1. Switch to Finder or another app with shorter menus and see whether the missing icon returns.
  2. Check the app’s own settings for an option to show its menu bar icon.
  3. Review the macOS Menu Bar or Control Center settings for supported system controls.

The useful question is which controls you want visible all the time, and which you only need occasionally.

Start with the controls already on your Mac.

Review the items you actually use. Look in each app’s settings for an option to show or hide its menu bar icon. macOS also offers settings for supported system controls; the location and available options differ by version.

On macOS versions that support it for the item, Command-drag can help arrange icons. Some indicators and controls are protected or behave differently.

Hiding the menu bar is a different setting.

Automatically hiding the entire menu bar changes when the bar itself appears. It does not give selected third-party icons their own second row. See Apple’s Menu Bar settings guide, selecting your macOS version for the relevant options.

Give occasional controls a second row.

A second-row workflow keeps chosen icons together beneath the menu bar. With OverflowBar, you select supported items in Settings, enable hiding, and use its arrow to access the row.

  1. Keep controls you check constantly in the original menu bar.
  2. Select occasional supported app icons for OverflowBar.
  3. Open the row and choose an icon to use its original menu or popover.

This can make a crowded menu bar easier to manage, including on a MacBook with a notch. It does not guarantee access to every obscured icon: protected controls and items without a safe, stable identity are excluded.

Set up OverflowBar

Choose a menu bar manager for the way you work.

For a free, open-source Mac menu bar manager, OverflowBar offers a focused choice-and-second-row workflow. Ice and Thaw also offer separate bars, alongside broader management features. A second row is not exclusive to OverflowBar.

Compare the features you need: search, profiles, custom appearance, shortcuts, supported macOS versions, and release signing. OverflowBar currently does not provide search, saved visibility profiles, or a global toggle shortcut.

Check a project’s current release and compatibility documentation, rather than assuming that a screenshot or successful build proves support for your setup. Read the sourced Mac menu bar manager comparison.

Check permissions and compatibility before installing.

OverflowBar requires Accessibility for arrangement and activation. Screen Recording adds live previews and is optional. Captures stay on your Mac, while its updater contacts GitHub for updates.

The current release targets macOS 15 and 26 with a universal Apple silicon and Intel build. Physical macOS 15 and Intel testing remains incomplete. Native management is disabled on macOS 27 and later, whose runtime behavior was not tested for this release.

macOS menu bar behavior changes between releases. Revisit the compatibility notes when updating your operating system. Read OverflowBar’s current compatibility details.
