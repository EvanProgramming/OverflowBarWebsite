全部问题与故障排查
OverflowBar 免费吗？+

是的。你可以从 GitHub Releases 免费下载，或自行构建 GPL-3.0 开源代码，无需注册网站账户。

哪些 Mac 可以使用？+

通用构建面向运行 macOS 15 与 26 的 Apple 芯片及 Intel Mac。macOS 15 和 Intel 实体机验证尚不完整；macOS 27 及以上版本已禁用原生图标管理。 阅读兼容性说明。

为什么需要这些权限？+

辅助功能权限用于排列受支持的图标并打开控件。屏幕录制权限为可选项，用于实时预览；未授权时使用可用的应用图标。 了解权限用途。

可以恢复原来的菜单栏吗？+

可以。关闭 Hide selected icons 即可显示图标；Reset Icon Selection 还会清除已保存的选择。退出应用会恢复受管理的图标，并为下次启动保留你的选择。

会上传屏幕捕获内容吗？+

不会。预览捕获和图标选择保留在本机。Sparkle 更新器会连接 GitHub 检查签名更新，并在安装前征求同意。 阅读隐私说明。
