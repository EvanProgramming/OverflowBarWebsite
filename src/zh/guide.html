空间去哪了先看系统设置使用第二排选择管理工具了解限制

OverflowBar 可以在 macOS 15 与 26 上，将选中的受支持图标移到第二排。它无法管理所有被 MacBook 刘海遮挡的图标；受保护的控件和无法安全确定稳定身份的项目会被排除。先查看图标支持与排查说明和兼容性说明。

菜单栏图标去哪了？

同步工具、VPN、聊天应用和实用软件经常在菜单栏右侧添加状态图标；左侧的当前应用菜单也需要空间。MacBook 的摄像头刘海又进一步分割了可用区域。

空间不足时，图标可能难以访问或从视野中消失。具体行为取决于系统版本、显示布局、当前应用和相关状态图标。

首先想清楚：哪些控件需要一直看见，哪些只需偶尔访问？

先用好 Mac 自带的设置。

  • 检查应用自身设置，寻找显示或隐藏菜单栏图标的选项。
  • 查看当前 macOS 的“菜单栏”或“控制中心”设置，调整受支持的系统控件。
  • 切换到 Finder 或菜单较短的应用，观察缺失图标是否重新出现。

对于系统允许的项目，可以按住 Command 拖动排列。部分指示器或控件受保护，行为可能不同。

隐藏整条菜单栏，是另一回事。

系统的自动隐藏菜单栏选项，决定整条菜单栏何时显示，并不会为选中的第三方图标增加独立第二排。查看 Apple 的菜单栏设置指南，并选择与你系统一致的版本。

把偶尔使用的控件放进第二排。

第二排将选择的图标集中放在菜单栏下方。在 OverflowBar 中，先选择受支持的项目、启用隐藏，再通过箭头展开访问。

  1. 经常查看的控件留在原菜单栏。
  2. 偶尔使用且受支持的应用图标收进 OverflowBar。
  3. 打开第二排，点击图标使用原应用的菜单或弹窗。

这种方式有助于整理拥挤的菜单栏，包括带刘海的 MacBook，但不保证能管理每个被遮挡的图标。受保护控件及无法安全识别的项目仍会排除。

选择适合自己工作方式的工具。

OverflowBar 提供免费、开源、专注于选择图标和第二排的工作流程。Ice 和 Thaw 同样提供独立图标栏，并包含更广泛的管理功能；第二排并不是 OverflowBar 独有。

对比工具时，考虑搜索、配置方案、外观、快捷键、支持的系统及发布签名。OverflowBar 当前没有图标搜索、已保存的可见性配置或全局切换快捷键。

查看最新发布及兼容性文档，不要仅凭截图或构建成功就认定支持自己的环境。阅读有来源的 Mac 菜单栏管理工具对比。

安装前，检查权限与兼容性。

排列和激活图标需要辅助功能权限。屏幕录制是用于实时预览的可选权限。捕获内容保留在本机，更新器会连接 GitHub 检查更新。

当前通用构建面向 macOS 15 与 26，包含 Apple 芯片和 Intel 版本。macOS 15 与 Intel 实体机验证尚不完整；macOS 27 及以上禁用原生管理，相关运行行为未在本次发布中验证。

系统更新会改变菜单栏行为。升级 macOS 时，建议重新查看当前兼容性说明。
