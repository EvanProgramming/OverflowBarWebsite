Quick answer. A Mac menu bar manager helps organize status icons that compete for limited menu bar space. OverflowBar focuses on moving selected supported icons into a second row. Ice, Thaw, and Bartender describe broader toolsets that include features such as search, appearance controls, profiles, or automation; Hidden Bar focuses on a simpler hide-and-show workflow. The right choice depends on your macOS version, the items you need, and how much control you want.

Compare the workflow, not just the feature list.

Start with the problem you want to solve. Some people want one place to reach a handful of selected icons. Others want a search panel, profiles, hotkeys, or automatic rules. These approaches have different setup costs and trade-offs.

  • Access: Does the tool reveal hidden items in a second bar, a popover, a search panel, or by expanding the menu bar?
  • Scope: Can it manage individual supported items, whole apps, or both?
  • Compatibility: Check the current release, macOS version, and distribution channel. Features may differ between stable, beta, direct-download, and App Store builds.
  • Permissions: Read which system access is required, which is optional, and what happens when it is not granted.
  • Recovery: Look for a way to restore icons if a layout or OS update behaves differently than expected.

There is no single feature checklist that proves a manager works with every app. Apple changes menu bar behavior across macOS releases, and some system controls are protected.

OverflowBar: a focused second-row workflow.

OverflowBar is a free, open-source Mac menu bar manager for choosing supported status items and reaching them in a compact second row. You keep frequently used controls in the original menu bar, then open selected items from one arrow. The original app's menu or popover remains the control you use.

The current release targets macOS 15 and macOS 26. Accessibility permission is required for arrangement and activation; Screen Recording is optional and adds live previews. The community build is not notarized. Native icon management is disabled on macOS 27 and later. Physical macOS 15 and Intel validation is incomplete.

OverflowBar does not provide item search, saved visibility profiles, or a global toggle shortcut. It cannot manage every icon hidden by a MacBook notch: protected controls and items without a safe, stable identity are excluded. Read current installation and compatibility details before installing.

Ice: hide and reveal with appearance controls.

Ice is an open-source macOS menu bar manager. Its official site describes an Ice Bar below the menu bar, drag-and-drop arrangement, appearance customization, item spacing, and menu bar item search. Those features suit people who want more ways to organize and style their menu bar.

Check Ice's official feature page and current repository and releases for compatibility and behavior on your macOS version.

Thaw: a broader open-source toolbox.

Thaw's official project describes menu bar search, hotkeys, triggers, layout profiles, appearance options, and the separate Thaw Bar. Its install instructions distinguish releases by macOS version, with stable and beta channels that can have different capabilities.

If you want extensive customization or automation, review the official Thaw feature list and its current installation guide. Verify the channel and permission prompts for the build you plan to install.

Bartender: commercial controls and automation.

Bartender's publisher describes search, custom hotkeys, triggers, profiles, appearance options, and a Bartender Bar. The product is offered with a trial and paid plans; check the publisher's current pricing and trial terms.

Its current product page also describes a workflow for items obscured by a notch. See Bartender's official feature and pricing pages for the latest version details.

Hidden Bar: a simpler collapse-and-expand option.

Hidden Bar is an open-source utility centered on hiding and showing menu bar items. Its latest release notes say version 1.11.1 supports hiding on macOS 27 in the direct download; those notes also state that this method relies on a private Apple framework and requires Accessibility permission. The App Store build has different macOS 27 behavior.

Before installing, compare the exact version and download source. See the official repository and release notes.

Choose the tool that matches your setup.

  • You want selected icons in a dedicated second row: start with OverflowBar and confirm the icons you rely on are supported.
  • You want search and visual arrangement: compare Ice, Thaw, and Bartender against your preferred balance of customization and simplicity.
  • You want profiles, triggers, or extensive hotkeys: look closely at Thaw or Bartender's current feature set and release channel.
  • You only need a compact hide-and-show control: compare Hidden Bar's current build with your macOS version and distribution source.
  • You use a notched MacBook or a newly released macOS: verify exact version support and test the specific icons you depend on. A second-row feature does not guarantee access to every obscured or protected control.

Download links, permissions, and compatibility can change between releases. Use the publisher's current documentation rather than assuming an old review still describes today's build.
